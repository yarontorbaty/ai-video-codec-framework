# Creating LumaFlow Xcode Project

## The Problem
The Xcode project file I created was a placeholder and won't open properly. You need to create a real Xcode project and add the source files.

## Solution: Create Project in Xcode (5 minutes)

### Step 1: Create New Project

1. **Open Xcode**
   - Launch Xcode from Applications
   
2. **Create New Project**
   - File → New → Project (or Cmd+Shift+N)
   
3. **Choose Template**
   - Select **iOS** tab at the top
   - Select **App** template
   - Click **Next**

4. **Configure Project**
   - **Product Name:** `LumaFlow`
   - **Team:** Select your Apple ID
   - **Organization Identifier:** `com.yourname.lumaflow` (or similar)
   - **Interface:** **SwiftUI** ⚠️ IMPORTANT
   - **Language:** **Swift**
   - **Storage:** Core Data: OFF, Cloud Kit: OFF
   - Click **Next**

5. **Save Location**
   - Navigate to `/Users/yarontorbaty/Documents/Code/AiV1`
   - ⚠️ UNCHECK "Create Git repository"
   - Click **Create**

### Step 2: Add Source Files

Now we need to add the LumaFlow source code:

#### A. Delete Default Files (we'll replace them)
1. In Project Navigator (left sidebar), select these files:
   - `ContentView.swift` (we have our own)
   - `LumaFlowApp.swift` (we have our own)
2. Right-click → **Delete**
3. Choose **Move to Trash**

#### B. Add Our Source Files

**From Finder:**
1. Open Finder, navigate to:
   `/Users/yarontorbaty/Documents/Code/AiV1/LumaFlow/LumaFlow/`

2. **Drag these files** into Xcode's Project Navigator:
   - `LumaFlowApp.swift`
   - `Models/CaptureMode.swift`
   - `Views/ContentView.swift`
   - `Services/LiDARCaptureService.swift`
   - `Services/FileWriter.swift`
   - `Services/StreamingService.swift`
   - `Services/OnDeviceEncoder.swift`

3. In the dialog that appears:
   - ✅ Check "Copy items if needed"
   - ✅ Check "Create groups"
   - ✅ Ensure LumaFlow target is selected
   - Click **Finish**

**Or, manually add each file:**
1. Right-click on LumaFlow folder in Project Navigator
2. New File → Empty file
3. Copy contents from the files mentioned above

### Step 3: Configure Info.plist

1. Select **LumaFlow** (blue icon) at top of Project Navigator
2. Select **LumaFlow** target
3. Go to **Info** tab
4. Add these keys (click + at bottom):

**Camera Permission:**
- Key: `Privacy - Camera Usage Description`
- Type: `String`
- Value: `LumaFlow needs camera access to capture video with depth data`

**Photo Library:**
- Key: `Privacy - Photo Library Additions Usage Description`
- Type: `String`
- Value: `LumaFlow needs photo library access to save your recordings`

**Microphone (optional):**
- Key: `Privacy - Microphone Usage Description`
- Type: `String`
- Value: `LumaFlow needs microphone access to record audio`

### Step 4: Configure Capabilities

1. Still in the LumaFlow target
2. Go to **Signing & Capabilities** tab
3. **Signing:**
   - ✅ Check "Automatically manage signing"
   - Team: Select your Apple ID
4. Click **+ Capability** (top left)
5. Add: **ARKit** (search and double-click)

### Step 5: Set Deployment Target

1. In **General** tab
2. **Deployment Info:**
   - **iOS Deployment Target:** Set to `17.0` or lower if needed
   - **iPhone Orientation:** Check Portrait, Landscape Left, Landscape Right
   - **Requires Full Screen:** Check

### Step 6: Build & Run

1. Connect your iPhone 14 Pro Max
2. Select it in device dropdown (top toolbar)
3. Click **Play** button (▶️) or press Cmd+R

If you get build errors, let me know which ones!

## Troubleshooting

### "Cannot find 'ARSession' in scope"
**Fix:** Make sure you added ARKit capability (Step 4)

### "Cannot find 'CMSampleBuffer' in scope"  
**Fix:** Add these imports at top of files:
```swift
import AVFoundation
import CoreMedia
```

### "Type 'CaptureResolution' not found"
**Fix:** Make sure all files are added to the project target
